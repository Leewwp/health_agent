# 03 — 作息事实和计划入口最小闭环

**Parent:** GitHub #78

**GitHub:** [#81](https://github.com/Leewwp/health_agent/issues/81)

**What to build:** 用户输入“晚上几点前停止喝咖啡？”可以直接得到有来源的作息事实；“一周健身计划”等计划请求继续进入现有计划页面，不在聊天中生成新的计划算法或写入重复草稿。

**Blocked by:** #79 / 01 — 健身最小推荐闭环与意图安全基础。

**Status:** resolved

- [x] 咖啡因、睡眠、午睡、训练时段等简单事实请求直接返回 `ROUTINE` 事实，不强制追问起床时间或入睡时间。
- [x] 作息响应只返回 `ROUTINE` 资源，不混入餐食或健身展示块，也不受历史餐食/健身槽位影响。
- [x] 仅对明确的个性化作息安排保留有限澄清或现有计划入口；不增加作息 RAG、复杂调整或睡眠规划算法。
- [x] `PLAN` 请求继续复用现有周计划页面和写入保护，聊天不会自动创建草稿。
- [x] 补充作息、计划入口和跨领域历史隔离的 API 回归测试。

## Answer

`RoutineModule` 已将直接事实问题与个性化安排分流，作息结果只返回 `ROUTINE`；周计划继续通过既有页面入口，编排/API 回归已覆盖。
