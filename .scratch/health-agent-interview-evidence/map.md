# Health-Agent 面试证据与真实缺口收敛 - Wayfinder 地图

> Wayfinder 地图。本文件只维护目标、执行约束、已完成结论和范围边界；开放任务以子票为准。

- GitHub: https://github.com/Leewwp/health_agent/issues/71

## Destination

修复健康聊天中已经确认的真实链路缺口，并建立可复核的统一健康评估与分层 RAG 证据，使项目演示、仓库文档、自动化测试和简历表述保持一致，不通过新增自治 Agent 或分布式组件制造展示性复杂度。

## Notes

- **执行覆盖**：本地图显式允许后续会话把开发、测试、真实环境评测、浏览器验收和文档同步作为 `wayfinder:task` 推进。
- 优先级固定为：先修真实主链路缺口，再建设统一评估，最后扩充 RAG 评测证据。
- “计划入口衔接”指聊天识别到 `PLAN` 后提供真实可用的下一步动作；本批不默认授权聊天自动创建草稿。
- “统一健康评估”覆盖 `domain/task/risk/clarify/candidate/plan/fallback/latency`，不把旧饮食单意图和七槽位指标直接冒充三品类评估。
- “RAG 效果”只使用可复现报告中的数据；若无显著提升，保留架构与长尾分组价值，不编造整体提升数字。
- 每个实施会话先认领对应 GitHub 子票；前置票关闭后，后续票才进入 frontier。
- **已全部完成（2026-08-13，提交 6374494 + 9b85a42）**：#76 餐食检索透传用户原话、#72 PLAN 入口衔接、#74 反馈 traceId 精确归因、#73 统一健康评估（evalv2）、#77 分层 RAG 评测与消融。当前全量 631 测试为 595 通过、36 个环境门控跳过（MySQL 门控启用时 628 通过、3 个 Qdrant 门控跳过）；GitHub 各票已发验收评论并关闭；#76/#72/#74 附带真实浏览器验收，#73/#77 报告（`data/reports/health-eval-v2-report.*`、`rag_evaluation.json`）环境身份指向 6374494。
- 涉及 UI 的任务必须按父级规则通过运行中的真实浏览器验证，并记录 URL、交互和结果。
- 本地图不改变健康领域词汇和业务边界，因此无需修改 `CONTEXT.md`；评估术语属于工程证据口径。

## Decisions so far

- [#75 冻结统一健康链路评估与标注契约](https://github.com/Leewwp/health_agent/issues/75)：采用 `health-eval-v2`，分离 BENCHMARK/TRACE_AUDIT，以 36 条版本化 JSONL、确定性指标、结构化 Trace 事件和可追溯 JSON 报告构成面试向最小评估闭环；保留旧饮食入口，不建设评估平台或混合总分。

## Not yet specified

当前没有未锐化范围。统一评估契约已由 #75 冻结；本地图全部开放子票（#76/#72/#74/#73/#77）已实施、测试并关闭。

## Out of scope

- Agent 自主选择或调用 MCP Tool，以及应用通过 MCP/HTTP 回调自身。
- 第二后端实例、Redis 分布式锁、消息队列、Qdrant 集群和生产级高可用。
- 完整监控平台、全面压力测试和容量规划；本批只记录评估所需延迟与降级观测。
- 大规模周计划个性化、资源替换、自动重生成、提醒、打卡和长期行为追踪。
- 以无法复现的数字宣称 RAG “显著提升”。
