# “我的计划”TimeGrid 原型与页面

Status: resolved
Type: prototype
Priority: P0
Blocked by: 04

Prototype decision: [06-my-plan-final-prototype-decision.md](./06-my-plan-final-prototype-decision.md)

## Goal

制作全新的“我的计划”页面原型，验证周时间轴、移动端单日视图、资源选择弹窗、详情抽屉和未保存批量编辑。

## Scope

- 桌面 7 天横向 TimeGrid，默认滚动到常用时间；
- 移动端单日时间轴和日期切换；
- 全部/餐食/动作筛选；
- 点击空白格新增；
- 搜索、结构化筛选、仅看收藏和分页资源弹窗；
- 资源事实详情抽屉；
- 计划日期/时间/备注和动作处方编辑；
- 替换、删除、点击移动；
- 未保存状态、保存/取消、冲突失败和离开确认；
- 计划状态操作和历史删除。

## Design reference

参考 FullCalendar TimeGrid 的日期列、时间轴、半小时 slot、周/日切换和默认滚动时间；不要使用只有“第几节课”的课程表模型。

## Acceptance

- 桌面无不可用横向溢出；
- 移动端无横向溢出；
- 所有关键状态可通过真实浏览器操作到达；
- 资源选择不再使用巨大下拉框；
- 餐食热量不出现在可编辑输入中；
- 保存失败不丢失本地编辑；
- 原型使用现有 ES Module/共享详情边界，不引入前端框架。

## Final Prototype Baseline

- 唯一原型入口为 `#/prototype/my-plan`；A/B/C 比较变体已移除。
- 页面采用“可折叠计划库侧栏 + 横向七日卡片工作区”。侧栏默认展开，控制行包含折叠、计划库和新建计划；折叠后保留窄栏、状态点和悬停提示。
- 折叠状态下点击计划图标先展开侧栏再切换计划；点击新建先展开侧栏再进入草稿。
- 侧栏展开时七日工作区允许水平/垂直滚动；侧栏折叠时工作区取消固定最小宽度，七列自适应并在桌面端尽量完整可见。
- 餐食与动作保持不同颜色和文字类型标识；全部/餐食/动作筛选保留。
- 现有原型已经覆盖项目详情抽屉、空白日期新增、资源搜索/类型切换/仅看收藏/替换、删除、快速移动、批量保存/取消和未保存提示。
- 原型使用内存 fixture，不代表后端已完成；生产接入必须替换 fixture，但保留上述用户可见交互和资源事实/计划处方分离。

## Production Handoff

- 生产实现以该最终原型覆盖早期“纯 TimeGrid”抽象；计划库侧栏和七日卡片工作区是当前页面的布局基线。
- 新建、切换、启用、停用、复制、历史删除必须接现有计划生命周期 API，并按状态显示互斥操作。
- 资源选择弹窗接审核餐食/动作 Reader 和独立个人收藏集合；不得恢复巨大资源下拉框。
- 详情抽屉保留资源事实只读区和计划处方编辑区；餐食热量不作为可编辑字段。
- 原型的快速移动第一阶段可保留为明确目标时间按钮/选择目标时间格；桌面拖拽是后续专项，不得改变批量保存和服务端冲突校验边界。
- 原型完成后仍必须通过真实浏览器验证桌面和移动视口、侧栏折叠、计划切换、弹窗、抽屉、未保存和失败状态。

## Dependencies and fallback

- 依赖计划编辑契约、收藏集合接口和审核 Reader；
- 原型阶段可使用 fixture 数据，后端未就绪时不得伪造已保存成功状态；
- 桌面拖拽作为后续专项，第一版先使用点击移动。
