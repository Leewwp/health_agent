# 聊天布局与简洁澄清

Type: task
Status: ready-for-agent
Blocked by: none
Priority: P0
Estimated complexity: 中
External dependency: 无
Database migration: 否

## Goal

稳定聊天工作区并减少提示冗余。

## Scope

- 桌面端固定健康聊天、快捷问题和使用提示布局。
- 消息列表独立滚动，输入框保持可达。
- 移动端只让消息区滚动，辅助内容紧凑可展开。
- 普通澄清只给一个标准示例。
- 连续失败或歧义时才给额外格式帮助。

## Performance and Failure Contract

- 规则推荐目标 P95 小于 1 秒；模型等待必须显示状态，超过应用截止时间后给出可重试结果。
- 发送按钮、换一批和快捷问题在请求未完成时防重复提交；超时、失败和重试不会重复追加消息。
- 长对话、长资源名和 390px 宽度不得横向溢出；详情和辅助内容不能覆盖输入框。

## Acceptance

- 桌面和移动端无横向溢出。
- 长对话无需返回页面顶部即可使用固定区域。
- 普通训练时间追问简洁且仍能解析中文时间表达。
- 浏览器验收覆盖至少桌面和 390px 左右移动宽度。
- 浏览器验收记录桌面与移动 URL、视口、交互步骤、等待/失败恢复结果和截图证据。
