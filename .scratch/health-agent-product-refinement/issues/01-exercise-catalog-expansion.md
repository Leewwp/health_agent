# 动作目录自动补全与资格扩容

Type: task
Status: ready-for-agent
Blocked by: none
Priority: P1/P2
Estimated complexity: 中（浏览/单次推荐），很高（计划资格）
External dependency: 无；离线模型仅为可选增强
Database migration: 可能需要；必须保持导入幂等

## Goal

先将完整动作目录纳入浏览和单次推荐；周计划资格扩容作为独立的 P2 增强，不得阻塞 P0。

## Scope

- P1：用稳定分页开放完整目录，并使用已有字段进行单次推荐。
- P2：离线脚本/模型补全中文字段、难度、动作模式、风险标签、训练目标和基础剂量模板。
- 为每条记录写入补全版本和来源标记。
- 生成总数、排除数、字段补全和覆盖率报告。
- P2 才修改计划候选过滤和确定性校验，避免固定 30 条边界；默认保留现有 `plan_ready` 白名单。
- 候选先筛选，再传给 Training Plan Agent。

## Data Contract

- “真正损坏”必须有稳定机器原因，例如缺少稳定 ID、名称为空、记录无法解析；字段缺失本身不等于损坏。
- 未知补全字段使用显式 `UNKNOWN`，不得伪造风险或剂量；UNKNOWN 记录可浏览和单次推荐，但默认不得进入周计划。
- 导入按原始稳定 ID 幂等，报告至少包含总数、可浏览数、可推荐数、可计划数、排除原因、补全版本和输入数据版本。
- 计划资格扩容必须有独立开关、抽样检查和失败回退白名单。

## Acceptance

- 完整目录可分页浏览；非损坏动作可单次推荐。
- 计划可使用通过确定性校验的自动补全动作。
- 真正损坏记录有稳定排除原因。
- 不把完整目录一次性放入模型 Prompt。
- 既有资源读取边界架构测试仍通过。
- P1 失败时仍可使用现有审核子集；P2 数据质量不达标时不得扩大周计划候选。
