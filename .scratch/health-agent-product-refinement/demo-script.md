# 面试演示脚本

本脚本是本轮规格的最终用户侧验收证据。演示使用可重置的匿名身份和固定数据；P1/P2 能力不可用时，必须仍能完成 P0 主流程。

## 启动与重置

1. 按仓库 README 启动 MySQL、后端和前端反向代理；优先使用 fixture 或已准备好的本地数据，不依赖现场临时导入模型。
2. 确认 `/actuator/health` 为 `UP`，打开 `#/chat`，记录桌面视口和 390px 左右移动视口。
3. 使用新匿名会话开始演示。需要重置时清除浏览器会话 Cookie/本地会话标识，并按项目现有测试方式清理演示用户的草稿、当前安排和反馈；不得删除共享种子资源。

## P0 主流程

1. 输入“今晚想吃得清淡一点”，确认一轮得到晚餐和清淡语义，不出现重复餐次追问。
2. 查看餐食推荐卡片，点击“换一批”，确认保留需求且不返回本轮已经展示的资源。
3. 对一个资源点击“收藏”，对另一个资源点击“减少推荐”，确认页面状态可见；刷新或切换页面后收藏状态仍一致。
4. 输入训练需求并完成简报，生成一周训练计划草稿，确认周表显示日期、部位、时长、组数和次数。
5. 点击计划项目打开详情抽屉，确认先看到计划参数，再加载动作或餐食详情；模拟缺失/失败时不伪造详情。
6. 删除一个未采用草稿，确认需要确认且删除后不可再访问；对已确认计划执行“设为当前安排”或“取消当前安排”，确认取消不删除历史。
7. 在桌面长滚动聊天，在移动视口滚动消息区，确认输入框和必要操作仍可达且无横向溢出。

## 证据记录

每次验收记录 URL、视口、输入、结果、响应/等待状态和截图路径。失败时记录是否进入确定性降级；模型、Qdrant 或动作目录增强不可用不得被描述为 P0 失败，除非连确定性主流程也无法完成。
