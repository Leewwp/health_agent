# 训练计划能力边界与循证依据调研

> 对应 ticket：`.scratch/health-agent/issues/14-training-plan-evidence.md`  
> 调研与访问日期：2026-08-09  
> 适用范围：18～64 岁、一般健康、无相关症状且不处于医疗康复场景的成年人  
> 结论性质：产品能力边界与工程实现依据，不构成医疗诊断、治疗或个体化运动处方

## 结论摘要

1. `hasaneyldrm/exercises-dataset` 可以支撑动作浏览、按部位/器材/目标肌群筛选和动作说明展示，但**不能单独支撑训练计划生成**。官方 JSON Schema 明确没有难度、训练量、强度、负荷、时长、休息、恢复、进阶、动作替代、禁忌或适用人群等处方字段。
2. 一般成年人的公共健康目标有较强共识：每周 150～300 分钟中等强度有氧，或 75～150 分钟高强度有氧，或等量组合；另在每周至少 2 天进行覆盖主要肌群的中等或更高强度肌力活动。WHO 将这组成人建议评为**强推荐、总体中等确定性证据**。[S3]
3. 上述目标不是“所有初学者第一周必须完成的剂量”。WHO/HHS 都强调少量活动优于完全不动、应从少量开始并逐步增加；HHS 对低活动人群给出的低风险起点是每次增加约 5～15 分钟轻到中等强度活动、每周 2～3 次，并先增加时长和频率，再考虑提高强度。[S3][S4]
4. 抗阻训练可依据 HHS/ACSM 给出宽范围：主要肌群每周 2～3 天；初学者常用 8～12 RM；HHS 表述为每个动作 1 组 8～12 次有效，2～3 组可能更有效。[S4][S7][S8] 但数据集没有负荷与动作难度，MVP **不能据此自动给某个用户指定公斤数、训练至力竭或自动加重**。
5. WHO/HHS 公共指南没有给所有成年人规定统一的“48 小时恢复”阈值。MVP 可以把同一主要肌群的抗阻训练排在非连续日，作为保守的产品排程规则，但必须标注为工程安全策略，不应伪装成适用于所有人的精确医学结论。
6. 1～2 周 MVP 的合理承诺是：从人工审核的初学者动作白名单中，确定性生成一个带来源、可校验、可降级的“健康活动入门模板”；不能承诺医疗安全、伤病康复、精准负荷、专项增肌/力量表现、姿势纠错或个体化禁忌处理。
7. 本能力不需要 RAG。动作查询应使用结构化过滤，指南值应使用版本化规则/事实表，计划应由确定性组合器和校验器生成；LLM 只负责受约束的意图解释与自然语言说明，不拥有数值和安全规则的最终决定权。

## 1. 调研方法与证据分级

本报告优先核对以下一手材料：数据集维护者的 README/JSON Schema；WHO 正式指南及其 WHO 指南开发组论文；美国 HHS 正式指南；CDC 官方执行页面；ACSM 正式立场声明/共识声明在 PubMed 的原始摘要。没有使用健身博客、商业训练模板或搜索摘要作为结论来源。

证据标签仅用于本项目判断实现可信度，不替代各指南自己的 GRADE 评级：

| 标签 | 本报告定义 |
|---|---|
| A | 官方指南的强推荐，且有系统综述/GRADE 或同等级正式证据流程 |
| B | 官方指南/立场声明中的实践建议，但精确剂量受目标、人群或训练状态影响 |
| C | 为适配 MVP 增加的保守产品规则；与指南方向一致，但不是统一医学阈值 |
| 不可生成 | 缺少必要用户数据、动作元数据或专业评估，不能由系统或 LLM 猜测 |

## 2. exercises-dataset 字段核验

### 2.1 官方 schema 实际包含的字段

官方 README 与 `data/exercises.schema.json` 一致：每条记录只包含以下信息。[S1][S2]

- 标识与名称：`id`、`name`、`created_at`
- 分类：`category`、`body_part`
- 器材：`equipment`
- 动作说明：`instructions`、`instruction_steps`（10 种语言）
- 肌群：`muscle_group`、`secondary_muscles`、`target`
- 媒体：`media_id`、`image`、`gif_url`、`attribution`

JSON Schema 对动作对象设置了 `additionalProperties: false`，因此下表中的缺失不是“README 没写但数据中可能存在”，而是官方结构明确没有这些字段。[S2]

### 2.2 计划生成所需但缺失的字段

| 缺失类别 | 缺失字段/语义 | 直接影响 | MVP 处理 |
|---|---|---|---|
| 难度与经验 | beginner/intermediate/advanced、技术复杂度、学习成本 | 无法判断动作是否适合初学者 | 新建人工审核白名单与 `difficulty` 元数据；禁止从动作名称猜测 |
| 训练剂量 | 组数、次数、时间、节奏、动作速度 | 无法直接形成可执行处方 | 由版本化模板规则提供；数据集只提供动作身份 |
| 负荷与强度 | 公斤数、%1RM、RM、RPE、RIR、心率区间 | 无法个体化指定强度或进阶 | MVP 只使用相对强度/谈话测试和宽泛负荷措辞，不生成公斤数 |
| 组间与课间恢复 | 组间休息、同肌群恢复、疲劳状态 | 无法安排恢复或判断是否过量 | 排程器采用非连续抗阻日等保守规则；不声称精确恢复小时数 |
| 有氧处方 | MET、速度、坡度、时长、冲击等级 | 29 个 `cardio` 动作也无法直接折算指南分钟数 | MVP 把步行、骑行等活动类型单独建模，不从动作记录推算 MET/热量 |
| 风险与禁忌 | 伤病、疼痛、慢性病、孕期、药物、动作禁忌 | 无法按健康状况安全过滤 | 风险筛查先于动作召回；特殊人群退出具体计划生成 |
| 动作模式 | 推/拉/蹲/髋铰链/携带/旋转、单/双侧 | 仅凭身体部位无法保证计划平衡 | 白名单补 `movement_pattern`、`laterality` |
| 进退阶关系 | regression、progression、替代动作 | 无法安全地局部替换或逐周进阶 | MVP 仅允许人工维护的替代关系 |
| 环境与可达性 | 场地、器材规格、辅助人员、空间、噪音 | `equipment` 粒度不足以保证能执行 | 只支持少数标准器材枚举，其他场景提示用户确认 |
| 动作质量 | 常见错误、停止条件、监督需求、动作幅度限制 | GIF/说明不能评估用户实际动作 | 明示媒体仅供示意，不提供姿势识别或纠错承诺 |

额外风险：README 虽把该数据集描述为适合 workout planning applications，但这是用途描述，不是动作安全分级或运动处方证据。媒体的授权条款也不构成动作医学安全背书。[S1]

## 3. 一般健康成年人训练范围

### 3.1 有氧活动

| 维度 | 可引用范围 | 证据与解释 | 等级 |
|---|---|---|---|
| 周总量 | 中等强度 150～300 分钟，或高强度 75～150 分钟，或等量组合 | WHO 与 HHS 一致；中等与高强度可按约 2:1 分钟换算。[S3][S4] | A |
| 频率 | WHO 不规定唯一周频率；HHS 建议分散到一周，指出每周至少 3 天有益且可能降低受伤与过度疲劳；ACSM 2011 建议中等强度至少 5 天/周或高强度至少 3 天/周。[S4][S7] | “3～5 天/周”可作为模板范围，但不是所有人必须遵守的单一阈值。 | A/B |
| 相对强度 | 0～10 主观用力量表：中等强度约 5～6，高强度从 7～8 开始；CDC 谈话测试：中等强度能说话但不能唱歌，高强度说几句话就需停下来呼吸。[S4][S6] | 相对强度比固定速度更适合未知体能的 MVP。 | B |
| 绝对强度 | 中等强度 3.0～5.9 MET，高强度至少 6.0 MET。[S4][S6] | 数据集没有 MET，不能仅凭动作名称自动计算。 | A（定义）/不可生成（个体值） |
| 单次时长 | 当前 WHO/HHS 取消了必须连续至少 10 分钟才计入总量的旧限制，任何时长的中高强度活动都可累计。[S3][S4] | 不应把 ACSM 2011 的 20/30 分钟日处方误写成当前唯一有效的最短 bout。 | A |
| 初学者起点 | 从少量开始；HHS 指出在日常活动基础上，每次增加约 5～15 分钟轻到中等强度、每周 2～3 次，肌骨损伤风险低且无已知严重心脏事件风险；先增加时长和频率，再提高强度。[S4] | 这是起点，不是长期目标；进阶速度仍需按年龄、体能和经验个体化。 | B |

### 3.2 抗阻/肌力活动

| 维度 | 可引用范围 | 证据与解释 | 等级 |
|---|---|---|---|
| 频率 | 覆盖所有主要肌群，每周至少 2 天；ACSM 对初学者给出 2～3 天/周。[S3][S4][S7][S8] | “主要肌群”包括腿、髋、背、腹、胸、肩和臂。[S4] | A/B |
| 强度 | WHO/HHS：中等或更高强度；ACSM 2009：无抗阻经验者以 8～12 RM 负荷范围为常用起点。[S3][S4][S8] | 8～12 RM 表示只能以规范动作完成约 8～12 次的负荷，不等于任意轻重量做 8～12 次。 | A/B |
| 组数/次数 | HHS：每个动作 1 组 8～12 次有效，2～3 组可能更有效。[S4] | 对未受监督的新手，MVP 可从 1 组开始；不能把“可能更有效”转换成人人必须 3 组。 | B |
| 单次时长 | HHS 明确表示没有统一的肌力训练分钟数建议，处方由动作、组和次数描述。[S4] | 禁止为了填满计划卡片而让 LLM 编造“每次必须 45/60 分钟”。 | A（无统一值） |
| 进阶 | ACSM 2009：当个体能比目标次数多完成 1～2 次时，可将负荷增加约 2%～10%。[S8] | 该规则依赖可靠的实际负荷、完成次数和动作质量记录；MVP 不具备这些数据时应关闭自动加重。 | B/不可生成 |
| 恢复 | HHS 强调小幅超负荷后等待身体适应和恢复，并逐步增加；WHO/HHS 未规定所有人的统一 48 小时阈值。[S3][S4] | MVP 将同一主要肌群的抗阻训练排在非连续日，是保守排程策略，不是精确生理恢复预测。 | C |
| 组间休息 | ACSM 2009 针对不同目标给出不同休息策略，例如偏增肌训练常见 1～2 分钟、重负荷力量训练可达 3～5 分钟。[S8] | 初学者目标、动作和负荷未知时不能生成“唯一正确”组间休息；MVP 可给宽泛休息并允许用户按呼吸和动作质量延长。 | B/C |

### 3.3 恢复、热身和进阶不能过度承诺

- HHS 支持热身、冷身和肌力训练前使用较轻负荷，但没有为所有活动规定统一的热身/冷身分钟数。[S4] 因此 MVP 可以展示“先做轻量版本并逐步进入目标强度”，不应让 LLM 固定生成无来源的 5、10 或 15 分钟。
- 精确恢复时间受训练量、负荷、训练史、睡眠、营养、年龄和健康状况影响。当前数据集没有这些输入，系统只能做日历级错开和用户自评检查，不能预测“已完全恢复”。
- WHO 成人周总量建议是公共健康目标，不是运动表现训练上限。WHO 将超过 300 分钟中等强度或超过 150 分钟高强度的额外收益列为**条件推荐**，且证据存在收益递减与人群差异。[S3]

## 4. 初学者计划的安全承诺边界

### 4.1 MVP 可以服务的人群

仅在用户同时满足以下条件时生成具体入门模板：

- 18～64 岁；
- 自述无胸痛/胸部压迫感、眩晕、活动相关关节痛等当前症状；
- 自述无已知心血管、代谢或肾脏疾病；
- 非孕期/产后恢复期，不处于伤病康复或术后恢复；
- 目标是一般健康、建立活动习惯或基础体能，而非竞技表现、快速减重、康复或疾病治疗；
- 接受从轻到中等强度开始，并可在出现异常时停止。

ACSM 2015 运动前筛查共识把当前活动水平、相关症状/已知心血管-代谢-肾脏疾病、期望训练强度作为三个核心判断维度。[S9] HHS 同时指出：无已知慢性病且无胸痛/压迫感、眩晕或关节痛等症状的人，逐步开始轻到中等活动通常不需要先取得医疗许可；出现新症状时应咨询医疗人员。[S4]

### 4.2 MVP 应降级或转介的情况

| 情况 | MVP 行为 | 原因 |
|---|---|---|
| 胸痛/胸部压迫感、眩晕、活动相关关节痛，或增加活动后出现新症状 | 不生成具体计划；提示停止相关活动并咨询医疗人员 | HHS 的症状边界。[S4] |
| 已知心血管、代谢、肾脏疾病或其他需管理的慢性病 | 只展示公共指南和来源，不做个体动作/负荷处方；建议由医疗或运动专业人员适配 | ACSM 筛查三要素与 HHS 慢性病建议。[S4][S9] |
| 当前伤病、术后、康复、明显活动受限 | 不从通用动作库给替代动作；转介康复/医疗专业人员 | 数据集没有禁忌、活动度和康复阶段字段。 |
| 孕期/产后、65 岁以上、残障或跌倒高风险 | MVP 暂不生成具体计划；只展示对应人群指南入口 | WHO 对这些人群有额外建议，通用成人模板不足以覆盖。[S3] |
| 久坐/完全不活动者要求立即进行 HIIT、重负荷或力竭训练 | 降级为轻到中等强度起步模板 | HHS 建议低体能者避免从相对高强度开始。[S4] |
| 竞技、专项力量、增肌周期、快速减重 | 明示超出 MVP；不承诺结果 | 公共健康指南不是竞技训练方案，数据集也没有周期化所需数据。 |

这些排除项是**第一版产品范围**，并不表示上述人群不能运动；它表示当前系统没有足够信息和专业监督来安全地生成具体方案。

### 4.3 可以对用户承诺的表述

MVP 可以承诺：

- 计划数值来自版本化指南规则，并附来源；
- 只从人工审核的低复杂度动作池选动作；
- 计划通过总量、肌群覆盖、器材、日历冲突和风险规则校验；
- 对完全不活动者先给低剂量起点，不伪装为已达 WHO 周目标；
- 用户可反馈“过轻/合适/过重/疼痛/未完成”，系统下一次只在允许的规则内调整。

MVP 不得承诺：

- “绝对安全”“不会受伤”“保证减脂/增肌/变强”；
- 医疗诊断、康复动作、疼痛原因或疾病适应性；
- 精确公斤数、心率区、热量消耗、最大能力、动作幅度或恢复完成时间；
- 仅凭 GIF/文字即可保证动作正确；
- 由 LLM 自动发现某动作的禁忌、难度或替代关系。

## 5. 确定性规则与 LLM 边界

### 5.1 必须由规则和结构化数据决定

| 决策 | 确定性实现 |
|---|---|
| 是否进入具体计划生成 | 结构化健康筛查和硬性范围判断；字段缺失时默认不进入，而不是让 LLM 猜测 |
| 动作候选 | SQL/内存结构化过滤：白名单、器材、动作模式、肌群、难度、风险标签 |
| 周总量与强度 | 版本化 `guideline_rule`；中高强度等量换算、目标区间和来源固定 |
| 初学者阶段 | 根据基线活动和训练经验进入 `START_LOW` 或 `BUILD_TO_TARGET`，阶段转换需完成记录和用户确认 |
| 日历排程 | 抗阻日非连续、同日总量上限、可用日期与器材一致性；非连续日属于产品安全策略 |
| 计划校验 | 每项资源存在、动作来自白名单、主要肌群覆盖、数值在模板边界、来源完整、风险规则未命中 |
| 进阶 | MVP 默认关闭自动加重；未来只有在记录负荷、规范次数、RPE/RIR 和异常反馈后才能按规则计算 |
| 降级 | 缺档案、缺白名单元数据、规则版本失效或 LLM 输出异常时返回保守静态模板/来源，不生成自由文本处方 |

### 5.2 LLM 可以做什么

- 把用户自然语言映射为候选目标、器材、可用天数和偏好，但映射结果必须通过枚举/schema 校验，并由用户确认关键健康字段；
- 解释为什么本周从较少活动开始、如何使用谈话测试、某动作锻炼哪些肌群；
- 将已经通过校验的计划 JSON 组织成自然、克制的中文说明；
- 在不改动剂量、不新增动作、不移除警示和引用的前提下调整表达风格。

### 5.3 LLM 绝不能编造或覆盖什么

- 动作难度、禁忌、适用伤病、康复阶段、训练负荷、心率或热量；
- 用户未提供的疾病、疼痛、体能、1RM、动作熟练度和恢复状态；
- 指南数值、证据等级、来源 URL 和版本；
- 规则校验失败后“看起来合理”的替代计划；
- 基于动作名称或说明文本推断安全标签，并直接用于线上计划。

建议的数据流是：`用户输入 -> 结构化筛查 -> 白名单检索 -> 规则组合 -> 确定性校验 -> LLM 解释 -> 输出后再次校验`。任何 LLM 输出都不能成为计划 JSON 的事实源。

## 6. 适合 1～2 周 MVP 的能力范围

### 6.1 必做

1. **人工审核小型动作池**：从 1,324 条中只选约 20～40 个低复杂度、器材要求清晰的动作进入计划池；全量数据仍可用于浏览，但不能默认进入计划。
2. **补充计划元数据表**：至少包含 `exercise_id`、`beginner_allowed`、`movement_pattern`、`major_muscle_groups`、`equipment_code`、`impact_level`、`complexity`、`requires_supervision`、`risk_tags`、`regression_id`、`alternative_group`、`review_status`、`reviewed_at`。任何未审核记录默认不可生成。
3. **最小健康筛查**：年龄、当前活动水平、抗阻训练经验、症状、已知疾病、伤病/疼痛、孕产状态、目标强度、可用器材和日期。关键字段不允许 LLM 自行补默认值。
4. **两个确定性阶段模板**：
   - `START_LOW`：面向完全不活动/低体能用户；有氧从每次约 5～15 分钟、每周 2～3 次轻到中等强度起步；肌力可先 1 天轻到中等、每动作 1 组熟悉动作。明确显示“起步周，不代表已达到公共健康周目标”。[S4]
   - `BUILD_TO_TARGET`：面向已能稳定完成轻中等活动且无异常反馈的初学者；逐步走向每周至少 150 分钟中等强度等量活动和 2 个非连续全身肌力日。每动作可从 1 组 8～12 次起步。[S3][S4]
5. **相对强度工具**：只实现 0～10 RPE 与 CDC 谈话测试；不实现无传感器支撑的“精准心率区”。
6. **计划校验器**：校验动作白名单、风险状态、器材、总量、强度、主要肌群覆盖、非连续抗阻日、来源和免责声明。
7. **反馈闭环**：至少记录 `COMPLETED / PARTIAL / SKIPPED / TOO_EASY / APPROPRIATE / TOO_HARD / PAIN_OR_SYMPTOM`。`PAIN_OR_SYMPTOM` 触发停止自动进阶和风险提示。
8. **来源快照**：每份计划保存规则版本、来源标识和生成时用户档案版本，避免指南规则更新后历史计划无法解释。

### 6.2 明确不做

- 不做 RAG/向量检索来生成训练剂量；
- 不做自动公斤数、1RM 推算、心率区、卡路里和体重变化预测；
- 不做伤病康复、孕产期、老年跌倒、慢性病和残障适配计划；
- 不做摄像头姿势识别、实时动作纠错或可穿戴设备接入；
- 不做自动 2%～10% 加重和复杂周期化；
- 不从 1,324 条动作中随机生成“多样化”计划；
- 不把“48 小时”“每次 60 分钟”“必须 3 组”等写成无条件硬规则。

### 6.3 推荐的最小输出结构

```json
{
  "scope": "GENERAL_HEALTH_BEGINNER",
  "stage": "START_LOW",
  "guidelineVersion": "WHO_2020_HHS_2018_V1",
  "weeklyTarget": {
    "status": "BUILDING_TOWARD_TARGET",
    "moderateEquivalentMinutes": 45
  },
  "days": [
    {
      "day": "MONDAY",
      "type": "AEROBIC",
      "durationMinutes": 15,
      "intensity": "LIGHT_TO_MODERATE",
      "intensityCheck": "TALK_TEST"
    }
  ],
  "ruleWarnings": [],
  "sourceIds": ["WHO_2020", "HHS_PAG_2018"]
}
```

该结构示例表达的是“起步阶段和可追溯规则”，不是推荐所有人第一周都做 45 分钟。实际分钟数必须由阶段模板和用户基线确定。

## 7. MVP 验收基线

至少覆盖以下自动化验收：

1. 数据集 schema 审计测试确认不存在难度、剂量、负荷、恢复和禁忌字段，防止实现者误以为源数据已提供。
2. 计划中的每个 `exerciseId` 都存在于已审核白名单，`review_status != APPROVED` 时生成失败。
3. 缺少任一关键健康筛查字段时不生成具体动作和剂量。
4. 症状、相关已知疾病、当前伤病、孕产或超出年龄范围时按矩阵降级，不允许 LLM 绕过。
5. `START_LOW` 不声称已达到 150 分钟目标；`BUILD_TO_TARGET` 的中等强度等量分钟计算可复现。
6. 两个肌力日若命中相同主要肌群，不得安排在连续日；测试说明这是产品规则。
7. 没有负荷历史时，输出中不得出现公斤数、%1RM、自动加重百分比或“训练至力竭”。
8. 每份计划必须携带规则版本和来源；来源缺失时计划校验失败。
9. LLM 超时、JSON 非法或增加未审核动作时，系统返回确定性模板或错误，不接受“修辞合理”的非法计划。
10. 用户反馈疼痛/新症状后，后续计划停止自动进阶并进入风险提示路径。

## 8. 争议、限制与证据等级说明

1. **ACSM 2011 与当前 WHO/HHS 的频率表达不同**：ACSM 用“中等强度至少 5 天/周、高强度至少 3 天/周”的 FITT 表述；WHO/HHS 更强调周总量、分散到一周且任何 bout 均计入。MVP 应以当前 WHO/HHS 的周总量为不变量，把 3～5 天作为可调整模板，而不是硬编码唯一频率。[S3][S4][S7]
2. **150 分钟是公共健康目标，不是起步门槛**：WHO 的 150～300 分钟强推荐基于总体中等确定性证据；同一指南也明确低于该量仍有收益。MVP 必须区分 `START_LOW` 与“已达标”。[S3]
3. **超过 300 分钟的额外收益证据较弱**：WHO 将其列为条件推荐，且无法明确收益递减开始点。MVP 不应为了“更快效果”自动突破目标范围。[S3]
4. **抗阻训练精确处方不是同一证据层级**：HHS 的 1 组 8～12 次和 ACSM 的 8～12 RM 可作为一般范围，但具体动作、负荷、技术水平和目标会改变处方；将其应用到某个动作仍需要补充元数据和用户能力信息。[S4][S8]
5. **“48 小时恢复”不是本次一手材料中的统一阈值**：非连续日安排是合理的保守实现，但不能用于宣称生理上已经恢复，也不能替代疼痛/疲劳反馈。
6. **筛查不会消除全部风险**：ACSM 更新筛查是为了减少不必要的就医门槛，同时仍根据活动水平、症状/疾病和目标强度分流。[S9] MVP 只能降低明显风险，不能保证安全。
7. **数据集动作说明不是临床内容**：Schema 只保证字段结构，不保证每个动作适合初学者，也没有说明内容的医学审核过程。[S1][S2]

## 最终能力边界

第一版可以被准确描述为：**“针对一般健康成年人的、基于权威公共指南和人工审核动作池的可解释入门活动计划”**。

它不能被描述为：**“AI 私教自动生成个体化训练处方”**。要达到后者，至少还需要经专业人员审核的完整动作安全元数据、健康档案与训练历史、负荷/RPE/RIR/疼痛反馈、明确的进阶和回退规则，以及针对特殊人群的独立证据与审核流程。
