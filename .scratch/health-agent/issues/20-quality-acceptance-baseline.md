# 20 检索、计划与降级质量验收基线

- Type: grilling
- Status: open
- Blocked by: 10, 16, 19

## Question

如何定义“项目完成”，使 RAG、周计划和多品类对话可以用可复现指标验证，而不是只靠几次演示感觉正确？

待决策：

1. 意图/slot 基准集与状态机关键场景覆盖。
2. 混合检索的 Recall@K、结构化约束命中率、无 embedding 降级正确率。
3. 周计划能量区间、时间冲突、资源引用、风险规则和局部替换后的不变量。
4. LLM JSON 非法、DashScope 超时、Redis/MySQL 不可用、媒体 404 时的预期行为。
5. 冒烟链路、Testcontainers 范围、浏览器验收和部署后健康检查。

产出：验收矩阵、最小测试数据集、必须自动化的核心测试与可手工冒烟项。
