# 05 健身 slot 字典设计

- Type: grilling
- Status: open
- Blocked by: 14

## Question

健身 slot 字典（`diet_slot_option` 模式）的**三个新字段**的取值集合与数据映射（Q7 决策：方案 c = 部位 + 器材 + 训练目标）：

1. **训练部位**：中文取值集合（胸/背/肩/手臂/腿/核心/全身…）与数据集 10 个 body part（upper arms / upper legs / back / waist / chest / shoulders / lower legs / lower arms / cardio / neck）的映射——多对一或一对多？"全身"等聚合值是否需要？
2. **器材**：中文取值集合（徒手/哑铃/杠铃/器械/弹力带/壶铃…）与数据集 12 种 equipment 的归一映射。
3. **训练目标**：取值集合（增肌/减脂/塑形/耐力/柔韧…）与饮食现有 healthGoal 的关系（复用还是独立字段？跨品类澄清时怎么共存）。

审计约束：三个字段可以存在，但不应每轮都强制澄清。动作浏览/一次推荐只要求足以筛选候选的部位和器材；训练目标优先来自长期健康档案，仅在规划任务且缺失时澄清。目标肌群是动作属性；“喜欢俯卧撑”进入 17 号偏好模型，不进入 slot。

同时确定：①**目标肌群**只作动作属性和浏览筛选，不进入需求槽位；②部位、器材、训练目标哪些是长期档案、哪些是当前请求覆盖值；③种子数据与意图 agent 槽位抽取 prompt 的联动改动。

技能：/grilling、/domain-modeling。产出：三张取值映射表 + 种子数据清单 + prompt 改动点。
