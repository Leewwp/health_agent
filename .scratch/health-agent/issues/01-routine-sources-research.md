# 01 作息信息源调研

- Type: research
- Status: resolved

## Question

为"作息"品类寻找**可靠的信息来源**，让 agent 的作息建议"有据可依"而不是纯 LLM 生成（Q8 决策）。需要覆盖三类事实：

1. **年龄段与推荐睡眠时长**（如 18-64 岁 7-9 小时、65+ 7-8 小时等）——优先国内权威来源（如《中国睡眠研究报告》、国民睡眠健康白皮书）或 WHO/权威医学会指南。
2. **健身最佳训练时间段**（晨训 vs 晚间训练对睡眠、激素、表现的影响，是否存在普遍推荐）——优先学术综述、运动医学机构（ACSM/NSCA）或专家共识。
3. **作息相关的可量化参考**（如咖啡因截止摄入时间、光照/蓝光对入睡的影响、午睡建议时长等，若来源可靠）。

调研标准：可信度优先（官方/学术/权威机构），中文来源优先于外文，标注每条事实的原始出处（机构、文档名、链接）。甄别低质自媒体来源。

产出（写入 `.scratch/health-agent/research/routine-sources.md`）：①来源清单（机构、文档、链接、要点、可信度评级）；②建议落库"作息事实表"的候选条目清单（字段建议：事实类别 / 适用人群 / 数值区间 / 来源引用 / 中文措辞）；③结论与风险（哪些事实有争议、不宜写死）。

## Answer

由 research 子代理于 2026-08-09 完成，产出 `.scratch/health-agent/research/routine-sources.md`。

核心结论：
- 睡眠时长（★5 共识）：成人 18-64 岁 7-9 小时、65+ 7-8 小时（NSF 2015）；AASM 成人 ≥7 小时；《健康中国行动》倡导 7~8 小时——可落库。
- 训练时段（★4）：**无普遍最优时段**，晨/晚无显著差异，晚间中强度训练反而有助睡眠；应按昼夜节律类型（晨型/夜猫子）匹配——严禁写死"晨练最好"。
- 可量化参考：咖啡因睡前 ≥6 小时截止、睡前 2-3 小时避免亮屏（蓝光抑褪黑素）、午睡 20-30 分钟且 3 点前。
- 风险：午睡≥1h 与死亡关联为观察性证据，只能作带限定提示；部分中文官方链接需人工复核；cssm.org.cn 是冒充中国睡眠研究会的域名（排雷）。
