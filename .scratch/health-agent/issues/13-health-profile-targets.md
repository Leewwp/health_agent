# 13 健康档案与量化目标设计

- Type: grilling
- Status: resolved
- Blocked by: —

## Question

支撑推荐摄入区间、训练安排和作息目标的最小健康档案是什么，哪些数值由确定性规则计算，哪些信息仅用于过滤和解释？

已确认边界：第一版只服务 18 岁以上的一般成年人；数值必须来自明确公式并标注估算性质，LLM 不自行编造。

待决策：

1. 必填字段：年龄、生理性别、身高、体重、活动水平、目标；选填字段：时区、典型作息、训练经验、可用器材、饮食禁忌/过敏、伤病限制。
2. 能量与宏量营养目标的公式、上下限、舍入和缺失数据降级方式。
3. 临时对话 slot、长期用户档案和敏感健康约束如何分离，避免把长期事实塞进会话 JSON。
4. 档案更新后，既有计划是保留原快照、标记过期，还是自动重算。

产出：领域字段表、计算规则、校验规则、隐私边界和对计划生成的输入接口。

## Answer

2026-08-10 已决策：采用最小健康档案支撑第一版周计划。

- 必填：年龄、身高、体重、活动水平、主要目标。
- 可选：生理性别、时区、典型作息、训练经验、可用器材、饮食禁忌/过敏、伤病限制。
- 能量目标使用确定性公式计算，默认采用 Mifflin-St Jeor 基础代谢估算并结合活动水平得到区间；结果明确标记为估算值，不作为医疗处方。
- 缺少生理性别时使用更宽的估算区间，不由 LLM 补造数值。
- 临时对话槽位、长期健康档案和敏感硬约束分离保存；档案修改生成新版本。
- 已激活计划保留生成时的健康档案快照，不被静默重算；新档案只影响后续生成，并可将旧计划标记为可能过期。
