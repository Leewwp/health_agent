# 14 训练计划能力边界与依据调研

- Type: research
- Status: resolved
- Blocked by: —

## Question

现有 exercises-dataset 只有动作名称、步骤、部位、器材、目标肌群和媒体，无法直接支撑组数、次数、强度、训练频率、恢复和进阶规则。第一版训练计划可以安全、可解释地承诺到什么程度？

依据数据集官方字段和 ACSM/WHO 等一手指南调研：

1. 数据集缺少哪些计划生成所需字段。
2. 一般成年人有氧/抗阻训练频率、时长、强度与恢复的可靠范围。
3. 初学者模板、动作筛选和伤病限制的安全边界。
4. 哪些内容可以确定性规则生成，哪些必须降级为宽泛建议或转介专业人士。

产出：`.scratch/health-agent/research/training-plan-evidence.md`，作为 05、16、19 的前置事实。

## Answer

调研产出：`.scratch/health-agent/research/training-plan-evidence.md`。

结论：

- exercises-dataset 可以支持动作浏览和结构化筛选，但官方 schema 不包含难度、组数、次数、负荷、时长、恢复、进阶或禁忌，不能单独支撑训练计划。
- 第一版能力命名为“面向一般健康成年人的、基于权威公共指南和人工审核动作池的可解释入门活动计划”，不得称为个体化运动处方或 AI 私教。
- 全量 1,324 个动作在基础字段、媒体和许可合格时可浏览、收藏和单次推荐；自动生成计划按 `plan_ready` 条件判断，不设置固定的 20-40 条硬上限。计划资格需要补充难度、动作模式、风险、替代关系、适用人群和确定性入门模板；缺少这些元数据的动作仍可在提示后由用户手动加入草稿。
- 确定性规则负责健康筛查、动作过滤、周总量、日历排程和安全校验；LLM 只解释已校验计划，不编造负荷、难度、禁忌、心率、热量或恢复时间。
- MVP 使用 `START_LOW` 与 `BUILD_TO_TARGET` 两个阶段模板；同肌群抗阻日非连续是保守产品规则，不宣传为统一医学阈值。
- 胸痛/压迫感、眩晕、活动相关疼痛、已知相关疾病、当前伤病、孕产、康复及特殊人群不生成具体训练计划。
