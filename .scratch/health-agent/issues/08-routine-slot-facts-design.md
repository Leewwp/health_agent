# 08 作息 slot 字典与事实表设计

- Type: grilling
- Status: resolved
- Blocked by: 13

## Question

"作息"品类的 **slot 体系与事实表**如何设计（由 01 号调研结果毕业的 fog）？已确认事实（见 `.scratch/health-agent/research/routine-sources.md`）：睡眠时长（成人 7-9h、65+ 7-8h、健康中国行动 7~8h）、训练时段无普遍最优（按晨型/夜猫子匹配）、咖啡因睡前 6h 截止、睡前 2-3h 避免亮屏、午睡 20-30min。

待决策：

1. **作息输入类型**：起床时间、入睡时间、可用锻炼时段、工作/学习时间等是 `LocalTime`、时间区间或时长，不放进 `diet_slot_option` 枚举表；只有 chronotype、工作日类型等有限分类可使用选项字典。明确长期健康档案与本轮覆盖值。
2. **作息事实表**：表结构（字段：事实类别/适用人群/数值区间/来源引用/中文措辞）、落库哪几条事实（从 15 条候选中筛选）、如何避免"训练时段无普遍最优"这类争议事实被写死。
3. **消费方式**：按适用人群和事实类别查询少量事实，由规则组合器生成约束和来源，再交给 LLM 解释；不把整张事实表塞进 prompt，也不做向量检索。
4. **与健身/饮食的联动**：锻炼时段 slot 与健身"训练目标"的关系；作息 plan 与综合周计划（WEEKLY_PLAN）的关系。

技能：/grilling、/domain-modeling。产出：slot 字段表 + 事实表结构与种子数据 + 注入方式。

## Answer

2026-08-10 已决策：

- 起床时间、入睡时间、工作/学习时间和可用锻炼时段使用时间、时间区间或时长类型，不进入 `diet_slot_option` 枚举表。
- 昼夜节律、工作日类型等有限分类才使用选项字典；作息长期档案可以被本轮请求覆盖。
- 作息事实表保存事实类别、适用人群、数值区间、来源引用、中文措辞和证据限定。
- 成人睡眠时长、咖啡因截止时间、午睡时长和屏幕暴露等事实可以落库；“不存在普遍最佳训练时段”作为带限定的事实，不写死为晨练或晚练规则。
- 系统按适用人群和事实类别结构化查询少量事实，由规则组合器生成约束和来源，再交给 LLM 解释；作息不使用向量 RAG。
- 作息锻炼时段与健身训练目标在综合周计划中组合，但分别保持作息约束和健身目标的领域归属。
