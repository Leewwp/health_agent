# 19 健康风险策略与计划校验

- Type: grilling
- Status: resolved
- Blocked by: 04, 08, 13, 14

## Question

风险守卫如何从关键词替换扩展为覆盖饮食、训练、作息和综合周计划的分层策略，同时保持“健康建议而非医疗诊断”的边界？

待决策：

1. 必须拒绝、允许但提示、正常生成三档风险分类。
2. 过敏/禁忌、极端热量、伤病动作、过量训练、作息冲突等确定性规则。
3. 风险判断发生在候选召回前、计划组合时还是 LLM 应答后；各阶段分别拦什么。
4. 来源证据、免责声明和转介专业人士的展示规则。
5. 安全规则命中、误拦截和漏拦截如何进入 Trace 与评估集。

产出：风险矩阵、确定性校验器接口、文案规则和验收案例。

## Answer

2026-08-10 已决策：采用“拒绝具体计划、允许但提示、正常生成”三档风险策略。

- 候选召回前过滤过敏、明确禁忌和不允许的资源。
- 计划组合时校验极端能量目标、时间冲突、伤病动作、过量训练、恢复间隔和作息冲突。
- LLM 输出后再次校验结构、资源引用、数值来源和风险文案；LLM 不能绕过确定性风险规则。
- 胸痛、眩晕、活动相关疼痛、当前伤病、孕产、康复和需要医疗干预的情况不生成具体计划，只给出风险提示和专业转介建议。
- 低风险的生活方式建议可以正常生成；存在边界但仍可提供一般建议的情况必须带限定和来源。
- 风险命中、规则版本、误拦截、漏拦截和降级结果进入 Trace 与评估集，便于后续调整规则。
