# 19 健康风险策略与计划校验

- Type: grilling
- Status: open
- Blocked by: 04, 08, 13, 14

## Question

风险守卫如何从关键词替换扩展为覆盖饮食、训练、作息和综合周计划的分层策略，同时保持“健康建议而非医疗诊断”的边界？

待决策：

1. 必须拒绝、允许但提示、正常生成三档风险分类。
2. 过敏/禁忌、极端热量、伤病动作、过量训练、作息冲突等确定性规则。
3. 风险判断发生在候选召回前、计划组合时还是 LLM 应答后；各阶段分别拦什么。
4. 来源证据、免责声明和转介专业人士的展示规则。
5. 安全规则命中、误拦截和漏拦截如何进入 Trace 与评估集。

产出：风险矩阵、确定性校验器接口、文案规则和验收案例。
