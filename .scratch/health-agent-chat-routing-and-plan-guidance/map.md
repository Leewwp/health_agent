## Implementation order

1. P0：新建计划用户引导与生命周期原子转移——“新建”消费同轮原子写 OPEN+空简报+(侧,PLAN)，MEAL/EXERCISE 同规；回归必须种子 GENERATED/PAUSED 前置（防假绿）。
2. P0：澄清续轮继承边界与任务保真——继承保持 state.task() 禁止 PLAN→RECOMMEND 覆写；继承需字段值或任务证据；聊天/能力问句打断继承；澄清挂起设时效。
3. P0：最终任务闸门与共享硬证据词表——可执行证据白名单（词表/解析器续轮/结构化动作/模型双一致），模型单独判定不得启动任务；无模型轮以确定性判定替代双一致；收编四处漂移词表副本并加漂移守卫。
4. P0：独立 CHAT 回答服务、能力问句与澄清响应契约——CHAT 提示词与风险边界；能力问句不继承展示旧 domain/task 标签；伪槽位 key 清理。
5. P0：前端等待态、MODIFY_CURRENT_PLAN 点击路径与用户可见术语收敛。
6. 后续：聊天上下文绑定具体计划项目的推荐与候选替换。
