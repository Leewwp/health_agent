# 06: 前端等待文案、计划动作点击路径与术语收敛

**What to build:** 聊天页通用等待态统一显示“正在生成回答”（任务相关措辞只出现在完成响应里，不出现在通用 pending 指示器）；“修改当前计划”动作（`MODIFY_CURRENT_PLAN`）渲染为可点击按钮，点击走既有编辑副本路径（打开计划页编辑副本，与“追加到当前计划”同语义，ENABLED 计划不变），不再是死按钮；未知槽位 key 不再兜底渲染为可误解的中文标签；计划简报面板标题等用户可见文案收敛，不出现“简报”“当前字段”内部术语。

**Blocked by:** None (can start immediately)

**Status:** resolved（2026-08-31 实施完成：等待文案抽至 `ui/chat-waiting.js`“正在生成回答”；`MODIFY_CURRENT_PLAN` 与 `NEW_PLAN_BRIEF` 前端点击路径（前者导航计划页编辑副本，后者发送“新建”走挂起消费）；`SELECT_TASK` 渲染与点击；未知槽位 key 空串不渲染（前后端兜底标签出清，可补充项 join 过滤空标签）；简报术语从面板标题/综合文案退场；前端测试 47/47。浏览器验收：等待文案、按钮渲染与点击、编辑副本创建（24 项草稿、启用计划不变）、390px 无横向溢出全部通过；顺带修复 `withPlanBrief` 覆盖 actions 导致 MODIFY_CURRENT_PLAN 从未下发的隐藏缺陷）
