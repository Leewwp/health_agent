# 07: 聊天推荐结果替换具体计划项目（后续迭代，本轮不实施）

**What to build:** 用户在聊天中说“修改当前计划中周一的健身动作”，系统识别目标日期与资源类型；目标唯一时直接开始受约束推荐，目标多个时先列出候选项让用户选择要替换哪一个；推荐结果卡片提供类型化“替换这个动作/餐食”动作，点击后绑定或创建编辑副本、经乐观版本校验与资源资格校验后事务性写入——不直接改写 ENABLED 计划。自然语言日期不是稳定的项目身份（同日多资源时必须显式选择目标）。

**Blocked by:** 本轮全部票据（01-06）完成后作为独立迭代评估

**Status:** needs-info（已冻结可行性结论与安全边界，按规格推迟实施：属中高工作量功能，需新增聊天目标上下文、目标确认交互、推荐结果动作契约、编辑副本写入复用与后端安全/并发测试）
