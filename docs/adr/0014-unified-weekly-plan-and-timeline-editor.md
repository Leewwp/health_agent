# 统一综合周计划与时间网格编辑器

Status: accepted

健康 Agent 将用户可见的每一份周计划统一建模为可包含餐食和训练项目的综合周计划；餐食-only 与训练-only 只是项目集合不同，不再作为用户侧计划类型。计划生命周期采用“草稿、未启用、已启用、历史”：用户可以保存多份未启用计划，但同一用户同时只有一份已启用计划，切换启用只让旧计划回到未启用，停用后才允许将其转为历史。

当前启用计划改为用户级单一引用，聊天按当前请求领域从该计划读取当天对应项目。计划调整通过副本或未启用计划完成，支持审核资源的新增、替换、删除，以及半小时粒度的日期/时间移动和确定性训练参数调整；项目时间不得重叠。桌面端支持拖拽吸附，移动端采用“选择项目后点击目标时间格”的移动方式。生成时先按固定餐次窗口放置餐食，再在用户指定训练窗口中寻找不冲突的训练时段；没有可用时段时显式失败，不静默改写用户约束。

选择这一模型是为了让日常、减脂、增肌等多份计划可以并存并快速切换，同时让餐食、训练和综合计划共享一套详情、启用和编辑流程。代价是需要废弃现有按 `MEAL`/`EXERCISE` 分离的当前安排关系、移除启用新计划即归档旧计划的约束，并增加计划项目增删改、时间冲突校验和响应式时间编辑器。
