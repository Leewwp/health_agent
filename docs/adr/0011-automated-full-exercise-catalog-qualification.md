# 完整动作目录的权威导入与计划资格

本项目以本地 `exercises.json` 的 1324 条记录为动作目录权威源。导入保留 `(source_name, source_id)`、原始字段和数据库内部 ID；部位、器材、目标肌群、协同肌群和中文步骤展示字段由确定性映射/规范化流程生成，并与原始字段分列保存。源文件的 `image`/`gif_url` 仅是来源引用；没有独立、可核验的再分发许可时，媒体状态为 `NONE`，不得把源引用直接当作可发布图片或 GIF URL。

完整目录默认可浏览；动作是否可单次推荐或进入周计划由确定性资格字段和版本化审核规则决定。`plan_ready` 不是语言模型在线生成的属性，训练剂量也不由模型自由创造。计划生成和编辑只能消费 Reader 返回的合格资源，服务端会重新读取资源事实并校验用户提交的计划处方。

选择这一方案是为了让目录扩展可重复、可审计，同时保持资源事实和计划处方边界清晰。代价是派生标签、媒体和资格状态必须带来源/版本信息，源数据缺失时只能降级为不可用或只读能力，不能以推测填补。
